===== PAGE 4 =====

Model Types…
• Deterministic Model: an equation or set of 
equations that allow us to fully determine the 
value of the dependent variable from the 
values of the independent variables.
• Contrast this with…
• Probabilistic Model: a method used to 
capture the randomness that is part of a real-
life process.
• E.g. do all houses of the same size (measured 
in square feet) sell for exactly the same price?

deterministic model that approximates the 
relationship we want to model and add a 
random term that measures the error of the 
deterministic component.
